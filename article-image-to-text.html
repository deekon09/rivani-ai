What image-to-text OCR does

Optical character recognition (OCR) examines the shapes inside an image and predicts which characters, words and line breaks they represent. It is useful when text exists only inside a photo, screenshot, scan or receipt and you want an editable version instead of retyping it.

How to improve OCR accuracy

  • Use the sharpest source you have rather than a heavily compressed screenshot.
  • Keep the page straight and avoid perspective distortion where possible.
  • Make sure text has enough contrast from the background.
  • For very small text, use the Tiny Text Upscale option or enhance the image before OCR.
  • Select the correct language instead of asking one model to guess every script.
OCR confidence is not a guarantee

A high confidence score can still contain a wrong digit, name or punctuation mark. Review important output before using it in forms, records or published material.

Auto, Document, Screenshot, Table and Handwriting modes

Auto is the default for general images. Document uses a cleaner grayscale-style path for printed pages. Screenshot favors tiny digital text. Table / Receipt keeps line structure so a best-effort CSV export has more information to work with. Handwriting is experimental because general OCR engines are much less reliable on varied handwriting than on printed text.

Indian and World Languages

RIVANI includes an India & Common Languages group for English, Hindi, Marathi, Bengali, Gujarati, Tamil, Telugu, Kannada, Malayalam, Punjabi and Urdu, plus a separate World Languages group for Spanish, French, German, Portuguese, Arabic, Simplified and Traditional Chinese, Japanese, Korean, Russian, Italian, Dutch, Turkish, Indonesian, Vietnamese, Thai, Polish, Ukrainian, Hebrew and Persian.

Common bilingual choices such as English + Spanish, English + French, English + German, English + Portuguese, English + Arabic and English + Simplified Chinese are also available. The selected OCR language data is downloaded only when needed, so first use of a new language can take longer. Mixed scripts, decorative fonts and poor scans can reduce accuracy; always review names, numbers and official text.

What Smart OCR Race means

When Smart OCR Race is enabled, RIVANI prepares two versions of the image: a normal cleanup path and a stronger contrast path. OCR runs on both and the result with the higher reported confidence is kept. This can help difficult scans, but it also takes longer because OCR runs twice.

Table / Receipt mode and CSV export

The CSV button is a best-effort conversion, not a spreadsheet reconstruction engine. It looks for repeated spacing, separators and line structure in the extracted text. Complex merged cells, borders, multiple columns or very dense receipts may need manual cleanup after export.

Handwriting is experimental

Printed-text OCR and handwriting recognition are different problems. Neat block letters may work reasonably, while cursive writing, overlapping strokes, unusual pen styles and low-resolution notes can fail. RIVANI labels handwriting mode experimental instead of presenting it as guaranteed.

Browser-side processing

The image pixels are processed in the browser. The OCR library and selected language files are downloaded to the device, and browser caching may keep those technical files. RIVANI does not need to send the image itself to the account API to perform OCR.

What OCR can still get wrong

  • Similar characters such as O/0, I/l/1 and punctuation marks.
  • Low-contrast text over photos or gradients.
  • Curved labels, perspective distortion and text at unusual angles.
  • Very small text after social-media compression.
  • Complex tables and multi-column documents.
  • Handwriting, especially cursive or mixed writing styles.

Useful workflow

If the text is too soft to read, try Image Enhancer first. If the image is unnecessarily large, Smart Image Compressor can reduce file size before sharing it. For extraction itself, open RIVANI Image to Text, review the result, then copy or export it.
