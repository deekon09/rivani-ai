# RIVANI AI V25.6 — Detail, Export & GPU Balance

- Strong mode keeps up to 99.5% of a verified AI result; Fidelity Guard still Safe-Passes high-risk output.
- Text & Logo Safe no longer globally softens normal edge-rich photographs.
- Tone Lock uses a global exposure correction instead of overlaying source luminance, preserving high-frequency AI detail.
- Adaptive GPU pacing is slightly calmer on Balanced/Cool devices; Fast desktops remain near full throughput.
- Input RGBA is transferred directly to the image worker instead of cloned, reducing peak browser memory on large jobs.
- Export choices: PNG Master (pixel-lossless), Smart Smaller, WebP Max, JPEG Max.
- WebP/JPEG are explicitly labelled maximum-quality photo exports, not lossless.
- Result report shows megapixels, actual encoded format and actual file size.
- Large PNG masters explain why file size is high and offer a smaller photo-export path.
- Download extension now always matches the format actually encoded during the run.
- Audio Repair, LUKI and Cloudflare model routes are unchanged.
