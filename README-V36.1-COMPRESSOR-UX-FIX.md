# RIVANI AI V36.1 — Image Compressor UX Fix

Changed/new files only.

## Fixes
- Choose Images button now uses RIVANI blue/purple accent styling instead of a black-looking secondary style.
- Compression result now has a clear **Download Image** action.
- Added **Edit / Re-compress** for the currently selected image. It keeps the same original image, returns to controls, and the main action changes to **Re-compress This Image** so only that selected image is processed.
- Added **Compress Another Image**. It clears the previous working set and immediately opens the image picker for a fresh image.
- Result utility buttons and file-bar actions use tinted RIVANI blue/purple styles instead of black buttons.
- Existing compressor engine/quality logic is unchanged except for selected-image re-compression scope.
- Existing Audio Repair, Image Enhancer, and Background Remover processing/model files are untouched.
