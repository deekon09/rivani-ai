What Image Enhancer does

RIVANI Image Enhancer is a browser-first restoration and upscaling tool for images that are too small, soft, compressed or visually flat. It combines neural restoration with RIVANI's own finishing and verification steps so the result can become clearer without blindly accepting every detail produced by AI.

The tool is useful when the goal is sharper edges, cleaner compression, better local contrast and a larger usable image while keeping faces, text, logos, colors and important geometry as faithful as possible.

Smart Scan before enhancement

Smart Scan looks at the source before the expensive enhancement begins. It estimates blur/softness, noise and compression risk, lighting behavior, fine-edge sensitivity and transparency. Those signals are then used to adapt cleanup and finishing instead of applying the exact same sharpening recipe to every photo.

Users can choose a result style such as Natural, Strong or Restore. Natural aims for restrained improvement, Strong adds more visible enhancement, and Restore is intended for visibly degraded or compressed material.

Output scale and detail controls

  • 1× for restoration/finishing without a larger final dimension
  • 2× for moderate enlargement
  • 4× for the main neural super-resolution path
  • 8× for adaptive Studio enlargement

8× is not marketed as native 8× neural super-resolution. RIVANI first performs verified neural restoration at the proven scale, then uses Studio reconstruction to reach the larger effective output when the device can safely complete it. Very large jobs may automatically use the highest safe effective scale rather than crashing the browser.

Free detail controls include AI Strength, Clarity, Sharpness and Studio Finish. These affect how strongly detail and local contrast are presented after the restoration step.

Fidelity Guard: verify instead of blindly trusting AI

Fidelity Guard is the core safety idea of the enhancer. RIVANI compares the enhanced result back against the original at matched scale and checks for structural drift, color changes and excessive edge amplification. If the result starts moving too far away from the source, the tool can reduce how much AI detail is retained.

This does not prove that every generated pixel is factually correct. It is a practical guardrail designed to favor a faithful enhancement over a more dramatic but less trustworthy result.

What AI cannot do

If a face, letter or texture was never captured in the original pixels, no enhancer can know the exact missing detail. A sharper-looking result can still contain reconstructed detail, so important images should be reviewed at 100% zoom.

Pro precision suite

Pro is aimed at users who need repeatability, identity/brand protection and detailed verification rather than simply stronger sharpening.

  • Critical Area Lock: mark source areas that must remain anchored to the original.
  • Face Identity Lock: preserve selected facial geometry while allowing restrained enhancement. This is source anchoring, not face synthesis.
  • Face Reference Check: optional local visual comparison. It is not biometric identity recognition.
  • Logo Reference Lock: protect selected logo regions and optionally compare them to a clean reference.
  • Exact Brand Color Lock: pull near-matching verified colors toward a selected HEX brand color.
  • Selective Revert Brush: paint areas back toward the original after enhancement without rerunning AI.
  • QR / Barcode Guard: verify readable codes when the browser supports native barcode detection and restore the source code area if needed.
  • RIVANI Truth Map: visualize where the verified output changed most.
  • Print Proof: estimate 300-DPI print size and use print-oriented output bounds while preserving aspect ratio.
  • Batch + Consistency Lock: process up to 8 images sequentially using the same captured settings.
  • Unlimited image jobs for Pro entitlements.

Choosing an export

PNG is useful for lossless graphics and transparency but can become extremely large after 4× or 8× enlargement because pixel count grows quickly. WebP is usually the practical high-quality photo choice, while JPEG is useful when compatibility and smaller size matter more than transparency or lossless storage.

Limits and device behavior

  • Large images and large scale factors require much more memory; RIVANI adapts the working size or effective scale when needed.
  • Mobile and desktop can take different safe execution paths while keeping the same user-facing quality goal.
  • Very blurred faces, tiny text and heavily destroyed compression blocks may still be impossible to restore faithfully.
  • Filters and sharpening can be overused; compare the result with the original before export.

Privacy

The image pixels are processed in the browser. The required AI engine is downloaded to the device and can be cached by normal browser behavior. The current image enhancer is not built around uploading every source image to a paid RIVANI GPU server.
