Developer setup note
  1. Create a Firebase project on the free Spark plan.
  2. Enable Authentication → Google provider.
  3. For Facebook, create a Meta app, then add its App ID and secret in Firebase’s Facebook provider.
  4. Add your workers.dev domain to Firebase Authentication → Authorized domains.
  5. Copy the Firebase web configuration into assets/firebase-config.js.
